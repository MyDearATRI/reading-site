一句話核心命題（One-Sentence Core Thesis）

[original_text] 本論文在切範疇（Tangent Categories）的抽象微分幾何架構下，首度形式化定義了一般線性群對象（General Linear Group Objects, GL_A）與線性端同態分類子（Linear Endomorphism Classifiers, L_A），證明了 GL_A 可由乘法、單位與反向乘法的切三重等化子（Tangent Triple Equalizer）完全構造，且其微分李代數 \mathfrak{gl}_A = T_e(GL_A) 自然同構於 L_A 的最大微分子環 L_A^-，其李括號恰為交換子括號 [f, g] = f \circ g - g \circ f [PDF P24:L20-P25:L15, P31:L46-P32:L35]。

執行摘要（Executive Summary）

  1. 研究動機：在古典微分幾何與代數幾何中，GL_n(\mathbb{R}) 及其李代數 \mathfrak{gl}_n(\mathbb{R}) 是纖維叢、標架叢與李群理論的基石。然而在合成微分幾何（SDG）與公理化切範疇（Cartesian Tangent Categories）中，長年缺乏無坐標、無點集依賴的一般線性群內在表述。
  2. 多重線性閉切範疇：引入內部多重線性 Hom 對象 \mathcal{L}[A_1, \dots, A_n; B]，並針對微分對象 A 定義線性端同態分類子 L_A = \mathcal{L}[A; A]。
  3. 切三重等化子構造（Theorem 3.13）：無須依賴子對象分類子或拓撲開集概念，利用切等化子將群運算的結合律、單位律與逆元映射封裝為 L_A \times L_A 上的三重等化子，確定性構造 GL_A。
  4. 核心同構定理（Theorem 4.6）：利用 Eckmann-Hilton 論證，證明單位元切空間運算 T_e(m) 坍縮為加法運算 +，從而將三重等化子簡化為加法等化子，證明 \mathfrak{gl}_A \cong L_A^-。當切結構具備負元時，自動重合經典結果 \mathfrak{gl}_n(\mathbb{R}) \cong \mathrm{End}(\mathbb{R}^n)。

H3 核心定理推導與 5 層註釋

核心定理：一般線性李代數同構定理（Theorem 4.6）

1. 直觀理解

在經典微積分中，GL_n(\mathbb{R}) 位於矩陣空間 \mathrm{M}_n(\mathbb{R}) 中，是一個由行列式不為零 \det(M) \neq 0 定義的開子流形。因為開子流形的切空間與外圍空間相同，所以其在單位矩陣 I 處的切空間就是全部矩陣 \mathrm{M}_n(\mathbb{R})，且李括號為矩陣乘積的差值 [A, B] = AB - BA。本定理在完全沒有實數、極限、開集或坐標的「純範疇切結構」中，證明了這個經典事實依然必然成立。

2. 嚴格表述

設 (\mathbb{X}, T) 為多重線性閉笛卡兒切範疇，A 為微分對象，具備一般線性李群對象 GL_A 與線性端同態分類子 L_A。則 L_A 的最大微分子環 L_A^- 存在，且 GL_A 的微分李代數 \mathfrak{gl}_A = T_e(GL_A) 與微分李代數 L_A^- 自然同構，其李括號由複合映射決定：

[f, g] = m(f, g) - m(g, f)

3. 完整推導

  • 第一步：切三重等化子表示。由 Theorem 3.13，GL_A 是 L_A \times L_A 上乘法 m、單位 !e 與反向乘法 m^{\mathrm{op}} 的切三重等化子。
  • 第二步：函子 T_e 保持極限。因為單位元切空間運算 T_e 本質上是沿單位截面的拉回（Pullback），拉回保持極限，故 T_e(GL_A) 是 T_e(L_A) \times T_e(L_A) 上的切三重等化子。
  • 第三步：Eckmann-Hilton 坍縮（Lemma 4.5）。在切空間 T_e(L_A) \cong L_A 上，乘法的微分 T_e(m) 與微分對象的加法運算 + 重合，且 T_e(e) = 0。由加法之交換性，T_e(m^{\mathrm{op}}) = +^{\mathrm{op}} = +。
  • 第四步：三重等化子向加法等化子退化。原本要求 m(u, v) = e = m(v, u) 的三重等化條件，在微分後轉化為 u + v = 0。因此 T_e(GL_A) 恰為加法 + 與零映射 !0 的等化子。
  • 第五步：子環同構與括號保真。由 Definition 2.18，加法與零的切等化子恰為最大微分子環 L_A^-。進一步由 Lemma 4.4，自然映射 \chi_A: \mathfrak{gl}_A \to L_A^- 保持李括號運算 [f, g] = fg - gf。證畢。

4. 局限分析

本定理依賴範疇具備內部多重線性 Hom（即多重線性閉範疇）。對於無限維無拓撲完備化的空間（例如一般 Fréchet 流形），內部 Hom 對象可能不存在。此外，在無負元的切範疇中，\mathfrak{gl}_A 僅同構於可逆子結構 L_A^- 而非全體 L_A。

5. 研究拓展

為可微編程（Differentiable Programming）、高階神經網路反向傳播的幾何語義學，以及非阿貝爾主叢在量子幾何與凝聚數學（Condensed Mathematics）中的範疇化構造奠定了核心代數基礎。
