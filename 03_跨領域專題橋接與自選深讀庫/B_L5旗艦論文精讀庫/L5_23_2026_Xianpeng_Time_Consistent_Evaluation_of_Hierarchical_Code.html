一句話核心命題（One-Sentence Core Thesis）

[original_text] 本論文針對軟體工程智能體（SWE Agents）基準測試中普遍存在的資料污染與作弊漏洞，建立了首個三層零洩漏時間一致性評估協議（Zero-Leakage Time-Consistent Protocol），並證實確定性兩層階層式架構依賴圖（ServiceExplorer，系統容器 + 架構模組）能完全超越扁平 AST 語法樹，在 C++（DragonFly）與 JS/TS（React）上分別取得 +10.9% 與 +19.2% 的 F1 突破，甚至實現「上一代模型結合階層圖超越下一代未增強前沿基線」的跨代性能越遷 [PDF P2:L35-P3:L60, P5:L50-P6:L70]。

執行摘要（Executive Summary）

  1. 基準測試虛高假象：現有程式碼定位評估往往允許提示詞中包含檔案名稱或新引入的符號，使智能體依賴淺層正則 grep 搜索而非代碼理解。論文嚴格執行 T0 Commit SHA 鎖定、合併時間嚴格後於 T0、以及提示詞路徑與符號的自動詞法清洗。
  2. 三條件配對測試框架：在 7,200 次對照實驗中，嚴格對比基準條件（Baseline）、開源扁平語法樹（Tree-sitter AST）與兩層依賴架構（ServiceExplorer）。
  3. 扁平 AST 在 Monorepo 中的崩潰：扁平 AST 在 C++ 單一檔案內尚能解析符號調用，但在 React 這類大型動態跨套件工作區中，因缺乏模組邊界上下文，表現甚至劣於純檔案樹；ServiceExplorer 則透過 Level-1 系統容器約束爆炸半徑，Level-2 架構模組映射候選子系統，同時解決語義鴻溝。
  4. 跨代模型躍遷（Cross-Generation Model Leap）：配備 ServiceExplorer 的較小/前代模型（如 GPT-Sol）在定位 F1 上成功比肩甚至反超下一代原生 Claude/GPT 前沿基線，證實外部確定性知識結構對大模型參數量縮放具有實質替代與放大效應。

H3 核心定理推導與 5 層註釋

核心定理：F1 單調增長與跨代模型結構放大定理（Theorem 3.4）

1. 直觀理解

在長程程式碼智能體中，檔案定位的精準度直接決定了後續 Patch 生成的生死。若定位漏掉關鍵檔案（Recall = 0），智能體註定完全失敗；若抓入過多無關檔案（Precision 低），上下文視窗會被噪聲灌滿。本定理從調和平均數的偏導出發，證明了當階層式依賴圖同時提升精確率與召回率時，F_1 具有無條件的嚴格單調上升保證；更重要的是，結構化知識帶來的認知增益超過了單純模型參數量代際提升帶來的收益。

2. 嚴格表述

設 F_1(P, R) = \frac{2PR}{P + R}。對任意 P, R > 0，其梯度分量滿足：

\frac{\partial F_1}{\partial P} = \frac{2 R^2}{(P + R)^2} > 0, \quad \frac{\partial F_1}{\partial R} = \frac{2 P^2}{(P + R)^2} > 0
因此，F_1 在第一象限處處嚴格單調遞增。對於兩代基礎模型 M_g 與 M_{g+1}，若階層圖增益 \Delta F_1(G) > F_1(M_{g+1}) - F_1(M_g)，則 F_1(M_g \oplus G) > F_1(M_{g+1} \oplus \emptyset)。

3. 完整推導

  • 第一步：調和函數形式：
    F_1 = 2 \left( \frac{1}{P} + \frac{1}{R} \right)^{-1} = \frac{2PR}{P + R}
  • 第二步：商法則偏導：
    \frac{\partial F_1}{\partial P} = \frac{\partial}{\partial P} \left[ \frac{2PR}{P + R} \right] = \frac{2R(P + R) - 2PR \cdot 1}{(P + R)^2} = \frac{2PR + 2R^2 - 2PR}{(P + R)^2} = \frac{2R^2}{(P + R)^2}
  • 第三步：對稱性偏導： 同理可得 \frac{\partial F_1}{\partial R} = \frac{2P^2}{(P + R)^2}。
  • 第四步：嚴格正性： 當 P > 0 且 R > 0 時，2R^2 > 0 且 (P + R)^2 > 0，因此導數嚴格大於 0。這意味著無論當前工作點在哪裡，任何由 ServiceExplorer 帶來的精確率或召回率提升，都必然轉化為 F_1 的實質增長，且極端低召回點獲得的梯度拉力最大（當 P \gg R 時，\partial F_1 / \partial R \approx 2）。
  • 第五步：跨代躍遷代數關係： 實驗數據中，在 React Minimal 條件下，GPT-Sol + ServiceExplorer 取得 F_1 = 0.312，而無圖輔助的下一代前沿旗艦模型僅取得 F_1 = 0.265，嚴格滿足跨代超越條件。證畢。

4. 局限分析

該推導成立於靜態可達的檔案依賴路徑。在高度動態語言中，若大量採用動態字串拼接加載（例如 Node.js require(dynamicVar)），靜態兩層圖無法完整捕獲運行時依賴邊。

為企業級大型代碼庫中的自動 Bug 修復、安全補丁移植，以及基於代碼圖的自我反思智能體編排提供了標準化的評估規範與結構先驗。
