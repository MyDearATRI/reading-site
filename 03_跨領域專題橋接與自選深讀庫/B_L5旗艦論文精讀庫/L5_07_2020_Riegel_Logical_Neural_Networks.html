H0 多層次研究摘要

0.0 關鍵術語辨析：兩種同縮寫「LNN」之結構區隔 [外部知識]

在本研究庫 42_LNN液態與邏輯神經網路 領域中，縮寫 LNN 同時對應兩類數學本質截然不同的神經架構，閱讀時必須嚴格區分：

  1. 邏輯神經網路（Logical Neural Networks, Riegel et al., IBM Research, 2020，本文）：建立神經元與加權實值邏輯語法樹（Syntax Tree）之間的一對一同構映射，每個神經元輸出真值上下界區間 [L_v, U_v] \subseteq [0, 1]^2，透過離散步單調上下行傳播（Upward–Downward Pass）執行全向邏輯演繹，並以最小化邏輯矛盾損失 \sum_k \max\{0, L_k - U_k\} 進行端到端可微參數學習。
  2. 液態神經網路（Liquid Neural Networks / Liquid Time-Constant Networks, Hasani et al., MIT CSAIL, 2020/2021）：受線蟲神經系統啟發之連續時間非自治常微分方程（ODE）網路 \frac{d\mathbf{x}}{dt} = -\left[\frac{1}{\boldsymbol{\tau}} + f(\mathbf{x}, \mathbf{I}, t; \theta)\right]\mathbf{x}(t) + \mathbf{A} \odot f(\mathbf{x}, \mathbf{I}, t; \theta)，核心在於狀態依賴的動態有效時間常數與連續時間因果表徵（詳見末章 BRIDGE-3 之動力學橋接分析）。

0.1 一句話核心命題

[原文內容, Sec 1–2, P1:L33–P2:L43] 邏輯神經網路（LNN）將邏輯公式語法樹中的每個命題／謂詞與邏輯連接詞直接實例化為受約束的可微神經元，並在每個節點維護開放世界真值區間 [L, U]，藉此在單一架構中同時實現逐神經元符號可解釋性、有限步單調收斂的全向演繹推理（含機率界可靠性），以及基於矛盾損失最小化的抗不一致知識庫學習。

0.2 執行摘要（Executive Summary）

傳統神經網路擅長從含噪數據進行梯度學習，但內部表徵高度糾纏（entangled），缺乏精確的多步邏輯演繹與規則可控性；反之，古典符號定理證明器與描述邏輯推理機雖具備精確演繹能力，卻在面對知識不完整（Incomplete Knowledge）與本體不一致／雜訊規則（Inconsistent Knowledge）時極易崩潰（原理爆炸 Ex Falso Quodlibet），而馬可夫邏輯網路（MLN）或機率軟邏輯（PSL）等圖模型則將子句視為原子勢函數、依賴封閉世界假設（Closed-World Assumption）或昂貴的 MCMC 採樣 [原文內容, Sec 1, P1:L57–P2:L25]。

Riegel 等人提出的 LNN 透過四項核心設計打破上述對立：

  1. 語法樹一對一神經同構与加權實值邏輯 [原文內容, Sec 3, P3:L34–P4:L65; App B, P14–16]：每個邏輯連接詞（\neg, \land, \lor, \to）對應一個權重受約束（或採用動態定製激活函數）的神經元，一階量詞（\forall, \exists）對應在有限接地表（grounding tables）上執行 \min / \max 聚合的無參數節點 [原文內容, App A, P11–13]。
  2. 開放世界真值上下界 [L_v, U_v] 與四態語義 [原文內容, Sec 3, Table 1, P3:L45–L59; App F.2, Table 3, P27]：以真值閾值 \frac{1}{2} < \alpha \le 1 區分古典真 [\alpha, 1]、古典假 [0, 1-\alpha]、開放世界未知（如 [0, 1]）以及顯式邏輯矛盾 L_v > U_v。
  3. 全向雙向推論演算法（Upward–Downward Algorithm）與理論保證 [原文內容, Sec 4–5, P5–7; App C–D, P16–25]：上行傳播依子公式求母公式真值界，下行傳播利用連接詞之伴隨殘差／函數逆（對應 Modus Ponens、Modus Tollens、選言／聯言三段論）反向收緊子公式真值界。Theorem 1 證明單調連接詞下命題 LNN 必在有限步內 \epsilon-收斂；Theorem 2 證明採用非對稱 Fréchet–Boole 更新規則時，收斂區間必然包絡所有滿足初始理論 \Gamma_0 之古典機率測度的真實機率上下確界。
  4. 矛盾損失驅動之可微學習與梯度透明截斷 [原文內容, Sec 6, P7; App E–G, P25–42]：引入全網矛盾懲罰項 \sum_{k \in N} \max\{0, L_k - U_k\}，並提供兩套保持邏輯門語義的最佳化路徑，（a）帶鬆弛互補懲罰 \mathbf{s}_k \cdot \mathbf{w}_k 的線性約束規劃與直通梯度截斷（Gradient-Transparent Clamping），或（b）依權重動態平移四個控制節點的無約束定製激活函數（Tailored Activation Function） f_{\mathbf{w}}。

H1 研究背景、先修知識圖譜與分層閱讀路線

1.1 神經符號整合（Neuro-Symbolic AI）的三難困境

在 Riegel et al. (2020) 之前，結合統計學習與符號邏輯的主流路線各自面臨結構性瓶頸 [原文內容, Sec 1, P1:L45–P2:L25]：

  • 路線 A：規則轉譯型早期連線主義（如 KBANN [22]、Pinkas [14]、CILP [9]）：雖能將命題規則編譯為初始神經網路權重，但經無約束反向傳播訓練後，隱藏層神經元的決策超平面發生漂移，不再對應原本的 AND／OR 邏輯門，喪失事後符號可讀性。
  • 路線 B：馬可夫隨機場與統計關係學習（如 MLN [15]、PSL [1]、TensorLog [3]）：將每條一階子句視為單一純量權重的團勢函數（clique potential），遮蔽了子句內部的語法樹結構；且普遍依賴封閉世界假設（未觀測事實預設為假）或點估計軟真值，無法區分「高確信度中立真值 0.5」與「完全無資訊之未知 [0, 1]」。
  • 路線 C：向量嵌入型可微證明器（如 LTN [19]、NTP [17]、Neural Logic Machines [5]）：將常元與謂詞映射為高維稠密向量，雖可微但屬「類邏輯（logic-like）」近似，難以保證古典演繹的嚴格可靠性（例如在 Smokers & Friends 實驗中，LTN 無法完整推出朋友關係對稱性的邏輯後果 [原文內容, Sec 7, P8:L89–L92]），或僅限於 Horn 子句向後鏈結。

2.3 加權非線性邏輯與伴隨殘差蘊涵（Weighted Nonlinear & Residuated Logic）

4.1 核心結果一（Theorem 1）：命題邏輯雙向推論之單調性與有限步 \epsilon-收斂定理

直觀理解

傳統循環神經網路（RNN）在有環圖上反覆傳遞訊號時，極易因負回饋（如邏輯否定環 A \leftrightarrow \neg A）產生無窮震盪或混沌發散。LNN 之所以絕不震盪 [原文內容, Sec 2, P2:L40–L41]，關鍵在於每個節點更新真值界時採用的是單調收緊聚合算子 (L_z, U_z) \leftarrow (\max\{L_z, L'_z\}, \min\{U_z, U'_z\})：下界 L_z 只能單調遞增且被 1 封頂，上界 U_z 只能單調遞減且被 0 托底（即使發生 L_z > U_z 矛盾，兩者依然各自朝 [0, 1] 端點單調推進而不會往返跳動）。在有限個命題節點上，一組有界單調實數序列不可能無窮次邁出大於 \delta > 0 的步伐，因此總變化量必然在有限輪內小於任意給定容差 \epsilon > 0。

嚴格表述

[原文內容, Sec 4.3, P6:L69; App C.1, P19:L5–L17] 結合隱含有限性前提 [AI 推導, ASM-1]： 設命題邏輯神經網路 G_{\mathrm{LNN}} 包含有限個公式與原子節點，總計維護 n = 2|V| < \infty 個上下界純量變數 (L_z, U_z) \in [0, 1]^2。若否定算子 \neg:[0,1]\to[0,1]（單調非增）、加權析取算子 \oplus:[0,1]^{|I|}\to[0,1]（對各元單調非減）與非線性函數 f:\mathbb{R}\to[0,1]（單調非減）皆滿足單調性，且節點更新透過 aggregate 算子執行，則對任意容差 \epsilon > 0，演算法 3（inference）必在有限次迭代 T(\epsilon) < \infty 內終止，滿足單輪總變動量：

\sum_{z \in V} \left(|\delta L_z^{(T)}| + |\delta U_z^{(T)}|\right) \le \epsilon,
且每個序列 (L_z^{(t)})_{t \ge 0} 與 (U_z^{(t)})_{t \ge 0} 各自收斂至極限點 L_z^*, U_z^* \in [0, 1]。

完整推導

  1. 連接詞與上下行算子之區間保序性 [原文內容 + AI 推導補全, STEP-1]： 由第 4.2 節 [P5:L45–L50]，合取與蘊涵皆可由 \neg 與 \oplus 複合表出。當子公式區間收緊（即 L_x 增大、U_x 減小）時：
    • 在上行傳播（演算法 1／4）中：對 \neg x，1 - U_x 隨 U_x 減小而增大、1 - L_x 隨 L_x 增大而減小；對 \oplus，{}^\beta(\bigoplus_i L_{x_i}^{\oplus w_i}) 隨 L_{x_i} 增大而非減，{}^\beta(\bigoplus_i U_{x_i}^{\oplus w_i}) 隨 U_{x_i} 減小而非增；對蘊涵 x \to y，L'_z = {}^\beta(U_x^{\otimes w_x} \to L_y^{\oplus w_y}) 對 U_x 單調非增、對 L_y 單調非減。
    • 在 aggregate 步驟中，對任意節點 z 與第 t 輪迭代，定義為：
      L_z^{(t+1)} = \max\left\{L_z^{(t)}, L_z^{\prime(t+1)}\right\} \ge L_z^{(t)}, \qquad U_z^{(t+1)} = \min\left\{U_z^{(t)}, U_z^{\prime(t+1)}\right\} \le U_z^{(t)}.
    • 由於激活函數 f 與下行截斷值域均落在 [0, 1] 內，且初始界 L_z^{(0)}, U_z^{(0)} \in [0, 1]，故對一切 t \ge 0 恆有：
      0 \le L_z^{(0)} \le L_z^{(1)} \le \cdots \le L_z^{(t)} \le 1, \qquad 1 \ge U_z^{(0)} \ge U_z^{(1)} \ge \cdots \ge U_z^{(t)} \ge 0.
  2. 單調有界序列之 Cauchy 收斂性 [原文內容, App C.1, P19:L9–L13]： 由實數完備性（單調收斂定理），每個有界單調序列必為 Cauchy 序列並收斂於唯一極限 L_z^* = \sup_t L_z^{(t)} \in [0, 1] 與 U_z^* = \inf_t U_z^{(t)} \in [0, 1]。（反證：若某序列非 Cauchy，則存在步長 \delta > 0 使該界在無窮多個時刻發生 \ge \delta 的躍升或下降，累積超過 \lceil 1/\delta \rceil + 1 次後必越出 [0, 1]，矛盾。）
  3. 有限維一致收斂與演算法終止 [原文內容 + AI 推導補全, STEP-2]： 記全網共有 n = 2|V| < \infty 個上下界純量 \{b_1^{(t)}, \dots, b_n^{(t)}\}。對給定 \epsilon > 0，對每個座標 k \in \{1, \dots, n\}，由 \lim_{t \to \infty} b_k^{(t)} = b_k^*，存在有限整數 T_k(\epsilon) 使得當 t \ge T_k(\epsilon) 時 |b_k^* - b_k^{(t)}| \le \frac{\epsilon}{n}。取 T_{\max} = \max_{1 \le k \le n} T_k(\epsilon) < \infty（此步關鍵依賴 n < \infty，即 ASM-1。）。當 t \ge T_{\max} 時，由單調性 |b_k^{(t+1)} - b_k^{(t)}| \le |b_k^* - b_k^{(t)}| \le \frac{\epsilon}{n}，求和得：
    \sum_{z \in V} \left(|L_z^{(t+1)} - L_z^{(t)}| + |U_z^{(t+1)} - U_z^{(t)}|\right) = \sum_{k=1}^{n} |b_k^{(t+1)} - b_k^{(t)}| \le n \cdot \frac{\epsilon}{n} = \epsilon.
    因此演算法 3 的 while 迴圈至多在 T_{\max} 輪內必然終止。\blacksquare

局限分析

  1. 「單步變動量 \le \epsilon」不等於「距真實極限誤差 \le \epsilon」 [AI 推導, IMP-2]：附錄 C.1 證明了當 t 足夠大時必有 \sum_k |b_k^* - b_k^{(t)}| \le \epsilon（從而觸發停止條件 \sum_k |\delta b_k^{(t)}| \le \epsilon）；但反過來，演算法 3 在首次滿足 \sum_k |\delta b_k^{(t)}| \le \epsilon 時即停機。若某有環加權圖的更新算子收縮因子接近 1（例如每輪推進 \epsilon/2 持續百輪），提早停機時的累積殘差 \|b^* - b^{(t)}\|_1 可能大於 \epsilon。唯有在無環語法樹（最多 1–2 輪精確達 \delta = 0）或有理分母離散格（如無權重布林／Łukasiewicz 整數權重，步長有正下界故有限步精確達 \delta = 0）上，兩者才完全等價。
  2. 一階邏輯含函數符號時不可判定 [原文內容, App C.1, P19:L18–L22]：若允許後繼函數 s(x)，推論過程會不斷生成新接地項 P(a), P(s(a)), P(s(s(a))), \dots，使 n \to \infty，各接地雖獨立單調收斂，但全局網路可能永不終止（對應一階邏輯之半可判定／不可判定性）。

直觀理解

當我們說某命題 \sigma 的真值界是 [0.7, 0.9] 時，這在機率上究竟代表什麼？第 5 節給出了相當漂亮的精確機率語義（Nilsson Probabilistic Logic Semantics）：把所有 2^{|A|} 個古典真值賦值世界視為樣本空間 \Lambda，每個「模型」就是 \Lambda 上的一個機率分佈 p。初始知識庫 \Gamma_0 給定部分公式的機率上下界，定義出一個滿足約束的機率分佈多面體 P_{\Gamma_0}。為什麼不能直接用標準 Gödel 或 Łukasiewicz 連接詞來算機率上下界？因為兩個事件 S_x, S_y 的聯集機率滿足 \max\{p(S_x), p(S_y)\} \le p(S_x \cup S_y) \le \min\{1, p(S_x) + p(S_y)\}，下界遵循 Gödel t-conorm（\max），上界卻遵循 Łukasiewicz t-conorm（Boole 聯集界）。第 5 節巧妙地讓下界與上界採用這對非對稱激活函數，從而使每一次局部上下行收緊都不丟失任何一個合法機率分佈（P_{\Gamma'} = P_\Gamma，即 LEM-1），最終保證 LNN 算出的 [L_\sigma, U_\sigma] 必定安全包絡真實機率極值區間 [\inf p(S_\sigma), \sup p(S_\sigma)]。
