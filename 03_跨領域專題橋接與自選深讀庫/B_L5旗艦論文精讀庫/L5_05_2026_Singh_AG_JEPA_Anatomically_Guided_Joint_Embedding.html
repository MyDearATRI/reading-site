一句話核心命題（One-Sentence Core Thesis）

[original_text] 本論文提出解剖學引導之聯合嵌入預測架構（AG-JEPA）與縱向軌跡模型（Prog-AG-JEPA），利用無須人工診斷標籤的軟解剖覆蓋矩陣（Soft Coverage Matrix, C）與解剖引導上下文取樣，將神經退化關鍵腦區（海馬體、杏仁核、內嗅皮質等）的細粒度歸納偏置注入非對比 JEPA 特徵空間，在 ADNI/AIBL 基準上取得 0.886 之 CN/AD 診斷 AUROC 與優異的阿茲海默症縱向病程預測能力 [PDF P4:L21-P5:L92, P25:L53-P25:L75]。

執行摘要（Executive Summary）

  1. 臨床與架構問題：標準視覺遮蔽模型（MAE / I-JEPA）在 3D 腦部 MRI 上採用均勻立方體遮蔽，極易將體積微小的內嗅皮質（Entorhinal Cortex）等核心早發病變區 100% 遮蔽，造成無可見線索與梯度坍縮；反之，傳統監督分割模型又高度依賴耗時的人工密集標註。
  2. 軟覆蓋矩陣與解剖 Token 流：利用 FastSurfer 預先計算 5 對雙側關鍵腦區在空間 Patch 上的佔比分佈 C \in \mathbb{R}^{R \times N}，建立雙軌 Transformer 編碼器：空間 Patch 流 z^p 與專屬解剖 Token 流 z^a。
  3. 四向互補預測目標：透過 Patch 預測器 M_{pp}、解剖引導 Patch 預測器 M_{ap}、解剖預測器 M_{pa} 與區域對齊映射 M_{ar}，迫使解剖 Token 壓縮全腦宏觀資訊，空間 Token 保持高解析細節。
  4. 縱向預測架構（Prog-AG-JEPA）：引入時間間隔 \Delta t、年齡與腦體積共變量條件化預測器，在特徵潛空間直接模擬隨時間退化的病程漂移，認知分數下降與腦區萎縮預測顯著超越靜態模型。

H3 核心定理推導與 5 層註釋

核心定理：軟解剖加權區域特徵誤差有界性定理（Proposition 3.1 / Theorem 3.4）

1. 直觀理解

在神經退化分析中，臨床醫生關心的是特定解剖結構（例如海馬體）的整體退化信號，而非單一網格像素。若將每個網格特徵進行粗暴的硬分配（Hard Assignment），邊界處微小結構的特徵會被鄰近的大腦白質稀釋。本定理證明，透過將解剖區域連續體積比率作為凸組合權重 \sum_n C_{r,n} = 1，區域特徵誤差嚴格受限於 Patch 特徵的最大誤差，絕不會發生誤差放大，並能平滑抑制單一 Patch 的假影噪聲。

2. 嚴格表述

設 C \in \mathbb{R}^{R \times N} 為非負軟解剖覆蓋矩陣，滿足 \sum_{n=1}^N C_{r,n} = 1。對任意解剖區域 r，設目標區域特徵定義為 z_r^{\mathrm{reg}} = \sum_{n=1}^N C_{r,n} z_n。若神經網路在各 Patch 上的預測誤差均勻有界 \|\hat{z}_n - z_n\| \le \epsilon，則重構區域特徵滿足：

\|\hat{z}_r^{\mathrm{reg}} - z_r^{\mathrm{reg}}\| \le \epsilon

3. 完整推導

  • 第一步：誤差向量展開。考察區域特徵差值向量：
    \hat{z}_r^{\mathrm{reg}} - z_r^{\mathrm{reg}} = \sum_{n=1}^N C_{r,n} (\hat{z}_n - z_n)
  • 第二步：三角不等式放縮。對兩端取賦範向量空間上的歐氏範數 \|\cdot\|：
    \left\| \sum_{n=1}^N C_{r,n} (\hat{z}_n - z_n) \right\| \le \sum_{n=1}^N \|C_{r,n} (\hat{z}_n - z_n)\|
  • 第三步：利用係數非負性。因為 C_{r,n} \ge 0，可將標量提出範數外：
    \sum_{n=1}^N \|C_{r,n} (\hat{z}_n - z_n)\| = \sum_{n=1}^N C_{r,n} \|\hat{z}_n - z_n\|
  • 第四步：利用均勻上界與隨機矩陣行和約束。代入 \|\hat{z}_n - z_n\| \le \epsilon：
    \sum_{n=1}^N C_{r,n} \|\hat{z}_n - z_n\| \le \epsilon \sum_{n=1}^N C_{r,n} = \epsilon \cdot 1 = \epsilon
  • 結論：區域聚合映射的 Lipschitz 常數嚴格等於 1，保證特徵表示在區域尺度上的穩定性。證畢。

4. 局限分析

該界限成立於給定確定性覆蓋矩陣 C 的前提下。若在患有極度嚴重的腦積水或末期腦萎縮患者中，FastSurfer 的自動分割產生系統性形變漂移，則 C 本身可能產生幾何失真，此時需引入不確定性加權。

5. 研究拓展

可推廣至心臟 4D MRI 動態血流重建、腹部多器官癌症病竈轉移自監督學習，以及多模態影像基因組學（Imaging Genomics）的特徵共對齊。
