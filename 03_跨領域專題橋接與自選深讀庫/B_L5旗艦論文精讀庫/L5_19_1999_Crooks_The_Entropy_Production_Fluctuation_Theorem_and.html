形式化核心定義

定義 1（微觀軌跡與時間反演）： 設系統在相空間中的微觀狀態序列為 \Gamma = (x_0, x_1, \dots, x_M)，外場控制協議為 \Lambda = (\lambda_0, \dots, \lambda_M)。時間反演協議定義為 \tilde{\Lambda} = (\lambda_M, \dots, \lambda_0)，時間反演軌跡定義為 \tilde{\Gamma} = (x_M^*, \dots, x_0^*)，其中 x^* 為動量反號後的微觀相空間狀態。

H2 核心定理與嚴格推導體系

5-層核心定理專題解析：Crooks 波動定理及其至 Jarzynski 等式與熱力學第二定律的精確導引

1. 直觀理解

在微觀尺度（比如單個蛋白質分子或微米膠體粒子），分子撞擊的隨機漲落非常劇烈。如果我們用力拉開一個分子，每次做的功都不一樣，甚至有極小機率因為熱庫分子的偶然推動，出現外界做的功小於自由能差（看似違反第二定律）的「暫態自發做功」現象。Crooks 定理指出：做功 W 的正向過程與反向吸收功 -W 的倒流過程，其發生機率的比值嚴格遵循指數規律 \exp(\beta(W - \Delta F))。當做功恰好等於自由能差時，正向和反向發生的機率完全相等；而對巨觀物體，因為做功遠大於熱噪聲，反向過程的機率小到整個宇宙年齡都不會出現一次。

2. 嚴格表述

設經典隨機微觀系統與溫度為 T 的熱庫接觸，始末態處於正則系綜平衡態。對於任意非平衡驅動協議，做功機率分佈嚴格滿足：

\frac{P_F(+W)}{P_R(-W)} = \exp\left( \beta (W - \Delta F) \right)
且其直接推論為 Jarzynski 等式：
\langle e^{-\beta W} \rangle_F = e^{-\beta \Delta F}

3. 完整推導

考慮微觀路徑機率之比。依據馬可夫隨機動力學之微觀可逆性原理（細緻平衡條件）：

\frac{P(x_{t} \to x_{t+1})}{P(x_{t+1}^* \to x_t^*)} = \exp(-\beta q_t)
其中 q_t 為該步釋放至熱庫中的微觀熱量。 沿著整條軌跡 \Gamma，轉移機率之比為總釋放熱量 Q 的指數：
\frac{\mathcal{P}_F(\Gamma | x_0)}{\mathcal{P}_R(\tilde{\Gamma} | x_M^*)} = \exp(-\beta Q[\Gamma])
由於正向過程起始於態 A 的正則平衡分佈，反向過程起始於態 B 的正則平衡分佈：
P_A(x_0) = \frac{e^{-\beta E_A(x_0)}}{Z_A} = e^{\beta(F_A - E_A(x_0))}, \quad P_B(x_M^*) = \frac{e^{-\beta E_B(x_M^*)}}{Z_B} = e^{\beta(F_B - E_B(x_M^*))}
整條未條件化的無條件軌跡機率之比為：
\frac{\mathcal{P}_F(\Gamma)}{\mathcal{P}_R(\tilde{\Gamma})} = \frac{P_A(x_0) \mathcal{P}_F(\Gamma | x_0)}{P_B(x_M^*) \mathcal{P}_R(\tilde{\Gamma} | x_M^*)} = \exp\left( \beta (F_A - F_B + E_B(x_M^*) - E_A(x_0) - Q[\Gamma]) \right)
依據熱力學第一定律，內能變化滿足 \Delta E = E_B(x_M) - E_A(x_0) = W[\Gamma] + Q[\Gamma]，故 E_B - E_A - Q = W。 代入得單條微觀軌跡機率比值：
\frac{\mathcal{P}_F(\Gamma)}{\mathcal{P}_R(\tilde{\Gamma})} = \exp\left( \beta (W[\Gamma] - \Delta F) \right), \quad \Delta F = F_B - F_A
對所有做功等於 W 的軌跡子集求泛函路徑積分：
P_F(W) = \int \mathcal{D}\Gamma \mathcal{P}_F(\Gamma) \delta(W - W[\Gamma])
= \int \mathcal{D}\Gamma \mathcal{P}_R(\tilde{\Gamma}) e^{\beta(W[\Gamma] - \Delta F)} \delta(W - W[\Gamma])
= e^{\beta(W - \Delta F)} \int \mathcal{D}\tilde{\Gamma} \mathcal{P}_R(\tilde{\Gamma}) \delta(W + W[\tilde{\Gamma}]) = e^{\beta(W - \Delta F)} P_R(-W)
兩端相除，即得 Crooks 波動定理：
\frac{P_F(+W)}{P_R(-W)} = \exp(\beta(W - \Delta F))

進一步推導 Jarzynski 等式：

\langle e^{-\beta W} \rangle_F = \int_{-\infty}^\infty P_F(W) e^{-\beta W} dW = \int_{-\infty}^\infty P_R(-W) e^{\beta(W - \Delta F)} e^{-\beta W} dW
= e^{-\beta \Delta F} \int_{-\infty}^\infty P_R(-W) dW = e^{-\beta \Delta F} \times 1 = e^{-\beta \Delta F}
證畢。

4. 局限分析

該推導嚴格依賴於熱庫處於瞬時熱平衡，且系統在正向過程初始時完全達到正則分佈。如果系統在操作開始前存在非平衡殘餘或熱庫響應具有長程記憶效應（非馬可夫非平衡浴），則時間反演關聯將被破壞。

5. 研究拓展

隨機熱力學在生成式人工智慧（Diffusion Models）中的精確映射：擴散模型的正向加噪過程與反向神經網路去噪生成，在數學上精確對偶於 Crooks 時間反演路徑。Score Matching 損失函數本質上等價於在非平衡路徑空間最小化熵產生率。

H3 計算驗證與符號推導實驗

本套件包含兩項核心驗證：

  1. SymPy 符號積分變換化簡： 符號化簡被積函數 P_R(-W) e^{\beta(W-\Delta F)} e^{-\beta W}，證明指數項中的 W 精確抵消，剩下孤立的常數因子 e^{-\beta \Delta F}。
  2. NumPy 高斯非平衡功分佈交點與采樣模擬： 在耗散 W_{\text{diss}} = 1.0 k_B T、\Delta F = 2.0 k_B T 下數值構造正向與反向做功分佈，證實在 W = \Delta F 處 P_F(2.0) = P_R(-2.0) 嚴格成立（誤差小於 10^{-12}）；抽樣 10^5 條軌跡計算 Jarzynski 平均，精確逼近理論值 e^{-2.0} \approx 0.1353。

H5 跨領域對偶映射與研究啟示

機器學習對偶：生成式擴散模型 (Diffusion Models)

非平衡時間反演與做功分佈對偶於生成式擴散模型（Score-based SDE / Flow Matching）：正向朗之萬動力學漂移與加噪映射為正向協議，反向神經網路生成去噪映射為反向時間反演路徑；自由能差 \Delta F 映射為數據分佈的對數似然邊界，微觀不可逆耗散映射為擴散模型訓練的 KL 散度損失。
