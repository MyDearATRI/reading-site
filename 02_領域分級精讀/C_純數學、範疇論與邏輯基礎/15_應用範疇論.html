G1｜3 分鐘速覽

一句話說明

範疇論曾被調侃為「抽象廢話（Abstract Nonsense）」，應用範疇論把它變成一門研究各種系統如何互連、開放系統如何組合的學問（Science of Compositionality）。它不管單個黑盒內部是什麼材質做的，只用嚴格的代數與二維弦圖（String Diagrams）回答一個問題：把量子線路、機率推論、控制迴路、梯度反向傳播與經濟博弈像樂高積木一樣接起來時，整體行為怎麼由局部接口完全決定？

  • 這個領域要解決什麼問題？ 傳統科學擅長還原論（Reductionism）與封閉系統建模：物理學家寫出整個宇宙的哈密頓量，統計學家寫出固定變數集合上的聯合機率分佈，控制工程師寫出封閉的狀態方程。但在實際的工程、生態、大腦與現代 AI 工具鏈裡，系統都是開放的，並且以模組互相插接（Open & Interacting）。把兩個各自穩定的控制系統連起來可能會震盪，把局部資料庫合併可能產生不一致，隨機通道串聯或並聯時，條件獨立性也會跟著改變。過去各學科各自發明了互不相容的方塊圖（Feynman 圖、貝氏網路、訊號流圖、計算圖），卻沒有統一的數學語意。應用範疇論發現，這些圖其實都是對稱么半範疇（Symmetric Monoidal Categories）與多項式函子／雙向透鏡（Lenses）中嚴格的幾何定理證明。
  • 直覺模型（不用公式也能懂的比喻）： 傳統的一維公式像擠在單行文字框裡的義大利麵條程式碼。應用範疇論則像一塊有數學嚴格性保證的二維電路板（String Diagrams），加上一套雙向插座標準（Lenses / Polynomial Functors）：
    • 在弦圖裡，上下串聯是先後複合 g \circ f，左右並排是平行張量積 f \otimes g。只要兩張線路圖能在拓撲上連續拉直成一樣（不剪斷電線），背後的代數等式就 100% 保證相等。量子不可複製定理（No-Cloning）與隱形傳態，在弦圖上 literally 只是把一條彎曲的電線拉直（蛇形方程 Snake Equations）。
    • 雙向透鏡（Lens）與多項式函子則像現代互動系統通用的 USB-C 接口。每個模組同時有一條往前送狀態／預測的通道（Forward Pass），和一條往回傳梯度／價格回饋／環境輸入的通道（Backward Pass）。這樣一來，深度學習反向傳播、漢密頓力學與開放賽局（Open Games）就成了同一種代數積木。
  • 其他領域的研究者為什麼要關心它？它和哪些領域相接？ 它是整張星系圖裡的跨學科翻譯總機。Lawvere 充實範疇說明 OT_最優傳輸與跨域平移 中的 Kantorovich 對偶就是 Kan 擴展，並引出 Mémoli–Wan 的充實範疇 Gromov–Wasserstein 距離（連結 04_表示對齊與類比）。Markov 範疇用純合成公理重構 36_貝氏逆問題與測度傳輸 與 37_因果推論與反事實最優傳輸 的條件獨立與充分統計量。雙向透鏡與反向導數範疇則統一了 03_數學結構化ML 的自動微分、09_社會與多智能體 的開放賽局與 21_形式語意與語言學 的分佈組合語意（DisCoCat）。

主要概念（白話說法對照嚴格定義）

  1. 充實範疇與 Lawvere 度量空間：邏輯、距離與最優傳輸的共同框架（Enriched Categories）

    • 直覺理解：普通範疇問的是兩個物件之間有哪些箭頭（一個集合 \operatorname{Hom}(x,y) \in \mathsf{Set}）。1973 年 Lawvere 換了一個問法：如果不用集合來裝箭頭，改用非負擴展實數半環 ([0,\infty], \ge, +, 0) 來度量從 x 走到 y 的最小代價，會怎麼樣？這時恆等態射 0 \ge d(x,x) 就是自身距離為零，態射複合 d(x,y) + d(y,z) \ge d(x,z) 一字不差就是三角不等式。所以度量空間就是一種充實範疇。
    • 機制或核心表達式：設 (\mathcal{V}, \otimes, I) 為閉對稱么半範疇，\mathcal{V}-充實範疇 \mathcal{C} 為每對物件賦予同態物件 \mathcal{C}(x,y) \in \mathcal{V} 及複合態射 \mathcal{C}(y,z) \otimes \mathcal{C}(x,y) \to \mathcal{C}(x,z)。當 \mathcal{V} = ([0,\infty], \ge, +, 0) 時：
      • 充實函子 F: X \to Y 即 1-Lipschitz 映射 d_X(x,x') \ge d_Y(Fx, Fx')。
      • 充實伴隨與左右 Kan 擴展 \operatorname{Lan}_i f(y) = \inf_{x} \{ d(i(x), y) + f(x) \} 直接退化為最優傳輸中的 c-變換與 Kantorovich–Rubinstein 對偶。Mémoli–Wan（2022）在這個基礎上定義任意兩個充實範疇之間的 Gromov–Wasserstein 距離，用來量化不同結構體系有多接近同構。
    • 能做到什麼，代價是什麼：布林邏輯（真值範疇即偏序集）、度量幾何、機率度量與成本最小化，都可以用同一套伴隨與米田嵌入來處理。代價是 Lawvere 度量本來就允許不對稱距離（d(x,y) \neq d(y,x)，上坡比下坡累）與無窮大距離。和古典歐氏直覺相比，它更接近有向熱力學與計算代價。

  2. 對稱么半範疇、弦圖與範疇量子力學（String Diagrams, PROPs & CQM）

    • 直覺理解：為什麼量子力學不允許完美複製未知量子態（No-Cloning），古典資訊卻可以隨便 Ctrl+C / Ctrl+V？Abramsky 與 Coecke 開創的範疇量子力學（CQM）用二維弦圖給了一個直觀的解釋。在緊閉么半範疇（Compact Closed Category）中，量子糾纏態是杯型彎線 \eta: I \to A^* \otimes A，測量投影是帽型彎線 \varepsilon: A \otimes A^* \to I。如果假設每個物件都同時有與糾纏相容的自然複製器 \Delta: A \to A \otimes A，把弦圖拉直之後，任何算子的跡都會坍縮為 1，範疇就退化了。在工程這一邊，Bonchi–Sobocinski–Zanasi 的交互 Hopf 代數（IH）用黑白兩套 Frobenius/Hopf 節點，完整公理化了線性動力學的訊號流圖（Signal Flow Graphs）。
    • 機制或核心表達式：在緊閉對稱么半範疇 (\mathcal{C}, \otimes, I, (-)^*) 中，對偶單位與餘單位滿足蛇形恆等式（Snake / Zig-Zag Equations）：
      (\varepsilon_A \otimes \mathrm{id}_A) \circ (\mathrm{id}_A \otimes \eta_A) = \mathrm{id}_A, \qquad (\mathrm{id}_{A^*} \otimes \varepsilon_A) \circ (\eta_A \otimes \mathrm{id}_{A^*}) = \mathrm{id}_{A^*}
      根據 Joyal–Street 定理，弦圖在平面同痕變形（Planar/Symmetric Isotopy）下的不變性，與對稱么半範疇公理完全等價且可靠（Sound & Complete）。
    • 能做到什麼，代價是什麼：繁雜的希爾伯特空間張量指標縮併與控制微分方程，可以化約成機器能自動重寫的圖形演算（量子編譯器 PyZX 的 ZX-Calculus 就是由此而來）。代價是純圖形語言主要刻畫有限維或代數骨架，遇到無窮維譜分解與連續極限時，需要結合 30_凝聚數學與合成微分幾何 或算子代數。

  3. Markov 範疇：不靠測度論的合成機率與統計學（Markov Categories）

    • 直覺理解：在古典測度論（Kolmogorov 公理）裡，光是證明一個正則條件機率存在，就要寫好幾頁 Radon–Nikodym 導數與標準 Borel 空間假設。機率推論在組合上其實很簡潔，這一點反而被蓋住了。Tobias Fritz 系統化的 Markov 範疇指出：隨機過程（Markov Kernels f: X \leadsto Y）可以看成一個對稱么半範疇，上面配備了複製資訊 \mathrm{copy}_X: X \to X \otimes X 與丟棄邊緣化 \mathrm{del}_X: X \to I。關鍵特徵只有一條：「先擲骰子再把結果抄兩份」不等於「獨立擲兩次骰子」。也就是說，隨機態射不與 \mathrm{copy} 交換，只有確定性態射才交換。
    • 機制或核心表達式：在半笛卡爾對稱么半範疇（單位元 I 為終物件，故每個物件有唯一丟棄映射 \mathrm{del}_X）中，為每個 X 賦予交換餘單子結構 (\mathrm{copy}_X, \mathrm{del}_X)。態射 f: X \to Y 稱為確定性的（Deterministic），當且僅當：
      \mathrm{copy}_Y \circ f = (f \otimes f) \circ \mathrm{copy}_X
      在這套純圖形公理上，條件化（Conditioning）、條件獨立性 X \perp\!\!\!\perp Y \mid Z、充分統計量，乃至 Fisher–Neyman、Basu 與 Bahadur 定理，都變成短短幾步弦圖變形。2026 年 Vaccarino 與 Das–Suda 進一步在 Markov 範疇中刻畫統計模型的自然變換意義與遍歷系統接合（Joinings）。
    • 能做到什麼，代價是什麼：一套框架同時涵蓋離散機率、高斯線性系統、Giry 單子測度核與非確定性自動機。代價是「幾乎處處相等（Almost-sure Equality）」要在範疇內另外引入子態射等價關係，部分經典定理也仍依賴具體實例滿足「存在所有條件分佈」這條公理。

  4. 多項式函子與雙向透鏡：互動、賽局與深度學習的共用接口（\mathsf{Poly} & Bidirectional Lenses）

    • 直覺理解：任何與世界互動的主體（一個神經網路層、一顆細胞、一個賽局玩家、一個使用者介面）都在做兩件事：向外展示當前的狀態／輸出位置（Positions），並接收環境針對該狀態傳回的方向／反饋／輸入（Directions）。Spivak 與 Niu 研究的多項式自函子範疇 \mathsf{Poly}，把這種依賴於當前位置的回饋介面寫成多項式 p(y) = \sum_{i \in p(1)} y^{p[i]}。\mathsf{Poly} 之間的單一態射展開來，本身就是一對前向與反向耦合的雙向映射（Dependent Lens）。
    • 機制或核心表達式：兩個單項式介面 \binom{A}{A'} = A y^{A'} 與 \binom{B}{B'} = B y^{B'} 之間的 \mathsf{Poly} 態射（即雙向透鏡 Lens）由一對映射 (f, f^\sharp) 構成：
      f: A \longrightarrow B \quad\text{（前向傳遞狀態／輸出）}, \qquad f^\sharp: A \times B' \longrightarrow A' \quad\text{（依賴於原狀態 }A\text{ 將下游回饋 }B'\text{ 拉回為 }A'\text{）}
      • 當 A' = T^*A 為餘切向量、f^\sharp(a, db) = (Df_a)^*(db) 時，透鏡複合精確等於深度學習的鏈式法則反向傳播（Reverse-mode AD）。
      • 當 B' 為未來效用回饋時，透鏡複合就是 Ghani–Hedges 的開放賽局（Open Games）。
      • 2026 年 Spivak 的新工作透過透鏡內在化（Lens Internalization），把梯度下降學習與漢密頓經典力學統一為同一個適配佈置運算元（Operad \mathsf{Arr}）上的函子語意。
    • 能做到什麼，代價是什麼：自動微分、強化學習、動態系統接線圖（Wiring Diagrams）與依賴類型程式驗證（如 2026 年 Aberlé 的 \mathsf{Poly} 驗證框架）因此有了同構的組合骨架。代價是要把抽象函子變成高效的工業軟體（如 AlgebraicJulia 生態），仍得仔細設計記憶體佈局與編譯器特化。

G3｜開放問題與跨域遷移

核心開放張力

學界目前的爭論與未解問題

  1. 連續時間隨機／非確定性開放系統的行為可表性（Clock Systems）：在範疇系統論（Categorical Systems Theory）中，確定性離散或連續動力系統的行為（Behaviors），可以表示為從時鐘系統（Clock System）打入系統的可表函子。但系統同時包含隨機布朗運動噪聲與非確定性選擇時，是否存在良態的時鐘系統，曾是長期未決的問題（2026 年 Lynch、Myers、Rischel 與 Staton 的新工作首次建構了隨機與非確定性系統的時鐘系統理論）。
  2. 從「靜態接線圖」走向「自修改動態拓撲（Dynamic Rewiring）」：傳統么半弦圖與 Operad 假設模組之間的連接拓撲在執行期間固定不變。但在生物形態發生（40_形態發生與多尺度生物計算）、多智能體臨時組隊與動態路由 MoE（01_Transformer核心）裡，連接關係本身會隨狀態演化。多項式函子 \mathsf{Poly} 的么半閉結構（動態連線取決於位置輸出）正被用來處理這個問題，但它的漸近穩定性與收斂分析才剛起步。
  3. 近似組合性（Approximate / Metric Compositionality）的誤差界：真實世界的機器學習特徵對齊與經驗資料不可能滿足嚴格交換圖（g \circ f = h），只能做到誤差 \varepsilon 內的近似交換。怎麼結合 Lawvere 充實範疇、OT_最優傳輸與跨域平移 的 Gromov–Wasserstein 鬆弛與高階同倫，建立一套量化範疇論，保證局部近似誤差在百萬層複合後不會爆炸，是純範疇論能不能接上實證科學的關鍵。

跨域結構遷移指南

可以借到其他領域的結構

  • 遷移至 03_數學結構化ML 與 10_工具鏈（Agent 工具鏈與神經模組的雙向 Lens 架構）：目前多數 LLM Agent 工作流（DAG 管線）只有單向的 Prompt 傳遞。如果改用 \mathsf{Poly}／雙向透鏡架構來設計 Agent 模組，讓每個工具節點除了前向輸出 f(a)，還必須實作結構化的反向歸因通道 f^\sharp(a, \Delta b)（回傳自然語言批評、信度修正或梯度訊號），整個非可微的 Agent 網路就有了端到端的組合式反向修正能力。
  • 遷移至 OT_最優傳輸與跨域平移 與 04_表示對齊與類比（充實範疇 GW 對齊）：概念空間不必只看成歐氏點雲。語意關係有方向性時（例如「狗 \to 哺乳動物」蘊含代價為 0，反向特化代價 >0），可以把兩個表徵空間建模為非對稱 Lawvere 充實範疇，再計算 Mémoli–Wan 的充實 GW 距離，這樣能同時對齊幾何距離與邏輯階層偏序。
  • 遷移至 37_因果推論與反事實最優傳輸（Markov 弦圖快速驗證識別性）：設計複雜的因果干預或隱變數識別演算法時，把機率和干預算子畫成 Markov 範疇弦圖（剪斷輸入線代表 do-干預），只靠在圖上移動線路，就能看出哪些混淆路徑被阻斷、哪些統計量是充分的。
