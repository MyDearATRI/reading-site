G1｜3 分鐘速覽

一句話說明

這個領域的架構不走「先把一切切成離散詞元，再做 O(N^2) 全域兩兩比對」這條路，改用連續時間動力系統（Neural ODE / SSM）、邊樣條函數逼近（KAN）、抽象潛空間預測（JEPA）與物理事件驅動／超維代數計算（SNN / Reservoir / HDC）。它們靠 O(1) 的推論狀態複雜度和貼近物理的先驗，來處理長序列與世界模型。

  • 這個領域要解決什麼問題？ 01_Transformer核心 在離散自然語言上是主流，但到了真實的物理與生物世界，有四個結構上不合用的地方：
    1. 超長連續訊號的二次方成本：面對百萬步基因組、高頻無線電通道、車聯網封包流或時間戳不規則的醫療波形，KV Cache 會不斷膨脹，在邊緣端維護不起。
    2. 逐像素／逐詞元生成把算力花在不可預測的雜訊上：世界上到處是隨風晃動的樹葉、醫學影像的底噪。要生成模型在原始像素空間猜出每個細節，反而模糊了高層語意與解剖結構。
    3. 多層感知機（MLP）的黑盒節點僵化：固定激活函數配稠密線性矩陣，很難抽出精確的符號公式，在科學小樣本回歸中也容易產生譜偏置。
    4. 馮紐曼同步時脈的能耗極限：人腦只耗電約 20 瓦，靠的是有脈衝事件才耗能的異步稀疏動力學，而不是每秒全網同步做浮點矩陣乘法。
  • 直覺模型（不用公式也能懂的比喻）： 如果把 Transformer 比成一位速記員，他把過去十年每一頁會議紀錄都攤在桌上逐字交叉比對，那麼這個領域有四種很不一樣的做法：
    1. 帶智慧閥門的流體管道（Neural ODE / S4 / Mamba / RWKV）：不留整疊舊報紙，只維護一缸精煉過的當前狀態流體。遇到關鍵訊號就打開閥門寫入，遇到無關雜訊就排掉。不管序列多長，推論時只帶這一只隨身水壺（O(1) 記憶體）。
    2. 把固定齒輪換成可塑凸輪曲線的精密機械（KAN）：傳統 MLP 在連線（邊）上只放簡單倍數，把固定的彎曲函數放在節點。KAN 反過來，節點只做加法，每一根連線都變成一條可以自由調整形狀的光滑樣條曲線。
    3. 只預測棋局走勢、不背誦棋盤木紋的大師（JEPA）：直接在抽象表徵空間預測被遮蔽區域的語意特徵，跳過繁瑣又容易產生幻覺的像素級重建。
    4. 有事才發電報的生物神經元與萬維全息記憶（SNN / 光子儲備池 / 超維計算 HDC）：直接借用光學延遲環，或萬維正交隨機向量的代數綁定，用毫瓦級功耗完成即時感知。
  • 其他領域的研究者為什麼要關心它？它和哪些領域相接？ 這個領域用動力學把 AI 和真實物理世界接起來。連續深度微分方程與時變液態網路通往 42_LNN液態與邏輯神經網路 與 27_算子學習與PDE基礎模型（如 2026 的 LNN-PINN）。HiPPO 正交多項式記憶與 Kolmogorov–Arnold 表示定理的數學根基在 03_數學結構化ML 與 16_ML數學地基。JEPA 非生成世界模型、脈衝神經網路與 Kanerva 超維向量代數，則是 08_情感腦認知（預測編碼與大腦海馬記憶）與 20_硬體與系統（神經形態與光子晶片）交會的地方。

主要概念（白話說法對照嚴格定義）

  1. 結構化與選擇性狀態空間模型及線性循環復興（S4, Mamba & RWKV）

    • 直覺理解：古典控制論的線性非時變（LTI）狀態空間模型有兩種等價的算法。推論時是一步一更新的 O(1) 輕量遞迴，訓練時又可以展開成全局一維卷積，用 FFT 平行算完。早期的 S4 用 HiPPO 矩陣把連續輸入歷史即時投影到正交多項式基底上，解決了萬步長程記憶問題。但它的轉移矩陣對所有輸入一視同仁（時不變），沒辦法像注意力那樣挑重點記、把不重要的忘掉。Gu & Dao 的 Mamba 改了這一點：讓步長 \Delta_t 與投影矩陣 (B_t, C_t) 直接成為當前輸入 x_t 的函數，再用硬體感知的平行關聯掃描（Parallel Associative Scan）繞開失去 FFT 後的訓練瓶頸。
    • 機制或核心表達式：把連續狀態方程 h'(t) = A h(t) + B x(t),\; y(t) = C h(t) 用零階保持（ZOH）離散化，得到步長為 \Delta_t = \mathrm{softplus}(W_\Delta x_t) 的選擇性遞迴（Gu & Dao, 2023）：
      \bar{A}_t = \exp(\Delta_t A), \qquad \bar{B}_t = (\Delta_t A)^{-1}\bigl(\exp(\Delta_t A) - I\bigr)\Delta_t B(x_t), \qquad h_t = \bar{A}_t h_{t-1} + \bar{B}_t x_t
      RWKV（Peng et al., 2023）則用指數時間衰減加權的鍵值比值取代點積 Softmax。訓練時可以像 Transformer 一樣平行展開，推論時可以嚴格折疊成固定維度的狀態更新。
    • 能做到什麼，代價是什麼：訓練期是 O(N) 線性擴展，推論期是 O(1) 常數記憶體／延遲，在基因序列、音訊與高頻感測流上明顯勝過同規模的 Transformer。代價是固定維度的隱狀態 h_t 是有損壓縮。遇到從十萬字中一字不差抄寫某組隨機密碼（In-Context Exact Copying）這類任務，仍受狀態容量限制，所以才出現與注意力混血的架構（如 Liquid-Transformer）。

  2. 連續深度微分方程與時變液態動力系統（Neural ODE, LTC & CfC）

    • 直覺理解：殘差網路 h_{t+1} = h_t + f(h_t, \theta_t) 就是用固定步長 \Delta t = 1 走歐拉法（Euler discretization）。Chen 等人（2018）把層數推到無窮連續的極限：不堆疊離散層，讓神經網路直接學狀態演化的速度向量場，再由自適應微分方程求解器決定步長，平緩處跨大步，劇烈轉折處走小步。Hasani 等人接著引入受生物突觸啟發的液態時間常數（LTC）與閉式解（CfC），讓系統的記憶時間尺度隨當下輸入強度即時伸縮（詳見專章 42_LNN液態與邏輯神經網路）。
    • 機制或核心表達式：Neural ODE（Chen et al., 2018，🏆 L5）把連續向量場參數化為 \frac{\mathrm{d}h(t)}{\mathrm{d}t} = f(h(t), t, \theta)，再用龐特里亞金伴隨靈敏度法（Adjoint Sensitivity Method）逆向積分伴隨狀態 a(t) = \frac{\partial \mathcal{L}}{\partial h(t)}。這樣不必儲存中間層激活值就能算出參數梯度：
      \frac{\mathrm{d}a(t)}{\mathrm{d}t} = -a(t)^\top \frac{\partial f(h(t), t, \theta)}{\partial h}, \qquad \frac{\mathrm{d}\mathcal{L}}{\mathrm{d}\theta} = -\int_{t_1}^{t_0} a(t)^\top \frac{\partial f(h(t), t, \theta)}{\partial \theta}\,\mathrm{d}t
      2026 年的 LNN-PINN（Tao et al., 2026）把時變液態殘差塊嵌進純物理微分算子損失，不需要觀測標籤，就能自適應地化解剛性（Stiff）PDE 的多尺度梯度失衡。
    • 能做到什麼，代價是什麼：架構本身就支援任意不規則採樣的時間序列和連續正規化流的精確對數概似計算，訓練記憶體是 O(1)、與步長無關。代價是數值 ODE 求解器在剛性區域的評估次數（NFE）無法預測，伴隨逆向積分也可能累積數值誤差。CfC（Hasani et al., 2022，🏆 L5）用緊緻閉式近似解提速 1 至 5 個數量級，針對的就是這個問題。

  3. 可學習邊樣條函數網路與非生成式潛空間預測（KAN & JEPA）

    • 直覺理解：這兩項工作一個改底層的神經元連線，一個改頂層的自監督目標：
      • **KAN（Kolmogorov–Arnold Networks）**的依據是蘇聯數學家 Kolmogorov 與 Arnold 的多元連續函數分解定理：任何複雜的多元函數，都能拆成有限個單變數連續函數的複合與相加。把可學習的 B-樣條（B-Splines）放到邊上之後，科學家可以直接看出每條邊學到的是 \sin(x) 還是 x^2，還能做符號公式修剪。
      • **JEPA（Joint-Embedding Predictive Architecture）**來自 Yann LeCun 對自迴歸／擴散生成路線的批評：真實世界有大量不可預測的微觀隨機性，要模型在像素空間重建被遮住的區域，只會讓它去背雜訊。改在抽象嵌入空間裡，從上下文區塊 s_x 預測目標區塊的表徵 s_y，才學得到高階因果與解剖結構。
    • 機制或核心表達式：
      • KAN 邊函數層（Liu et al., 2024）：第 l 層到 l+1 層之間沒有固定的線性權重矩陣，每個純量連接 \phi_{l,j,i} 都是基底函數與可學 B-樣條的線性組合：
        x_{l+1, j} = \sum_{i=1}^{n_l} \phi_{l,j,i}(x_{l,i}), \qquad \phi(x) = w_b\, b(x) + w_s \sum_{k} c_k B_k(x)
      • JEPA 潛空間預測目標（Assran et al., 2023）：上下文編碼器 f_\theta(x) 的輸出與潛變數 z 送進預測器 g_\phi，去對齊指數移動平均（EMA）目標編碼器 f_{\bar{\theta}}(y)，最小化表徵距離 \bigl\| g_\phi(f_\theta(x), z) - \mathrm{sg}\bigl(f_{\bar{\theta}}(y)\bigr) \bigr\|_2^2。
    • 能做到什麼，代價是什麼：KAN 在低維物理定律發現與 PDE 擬合上，用很少的參數就有更高的精度和符號可讀性，但在大規模電腦視覺／NLP 上，樣條評估比較難跑滿 GPU TensorCore。JEPA 不需要手工資料增強，自監督訓練效率也高出許多，不過本庫兩篇 2026 L5 審核論文指出了它的問題。面對阿茲海默早期很微弱的局域病灶，需要顯式引入解剖學區域引導（AG-JEPA）。醫療胸部 X 光的 JEPA 編碼器在黑盒對抗與對比度偏移下，嵌入幾何仍會出現裂痕（Cracks in Embeddings）。

  4. 儲備池物理動力學、脈衝神經網路與超維全息計算（Reservoir Computing, SNN & HDC）

    • 直覺理解：有些做法連用反向傳播更新內部權重都省掉。儲備池計算（Echo State Networks / Liquid State Machines）把輸入訊號送進一個固定不變的高維非線性物理系統（甚至可以是一圈光纖雷射延遲迴路），讓它激起豐富的暫態響應，然後只用線性回歸訓練最後一層讀出頭，就做到每秒百萬詞級別的高速分類（Larger et al., 2017）。脈衝神經網路（SNN）模擬生物膜電位，累積到閾值才發放離散的 0/1 脈衝。Kanerva 的超維計算（HDC）利用測度集中現象：在一萬維空間中，任意兩個隨機向量幾乎必然正交。它直接用元素乘法（綁定變數）、加法（疊加集合）與循環移位（編碼序列），做單次學習（One-shot Learning）和抗毀損的符號運算。
    • 機制或核心表達式：在 SNN 的漏積分發火（LIF）模型 C\frac{\mathrm{d}U}{\mathrm{d}t} = -g_L(U - U_{\mathrm{rest}}) + I(t) 中，發火階躍函數 S(t) = \Theta(U(t) - U_{\mathrm{th}}) 的導數不是零就是無窮大（Dirac \delta）。Eshraghian et al.（2023）系統整理了代理梯度法（Surrogate Gradient）：前向仍用離散二元脈衝以省電，反向傳播時把不可微的導數換成平滑的鐘形近似（如 \frac{\partial S}{\partial U} \approx \frac{1}{\pi(1 + (\pi U)^2)}），深度時空反向傳播（BPTT）因此可行。
    • 能做到什麼，代價是什麼：在神經形態晶片、光子硬體、無線通訊流體天線與高速機動車聯網（VANETs）上，可以做到很低的延遲、抗位元翻轉雜訊，以及微瓦至毫瓦級的推論。代價是在超大規模通用語言生成任務上，表達上限仍不及端對端訓練的稠密／狀態空間基礎模型。

G3｜開放問題與跨域遷移

學界目前的爭論與未解問題

  1. 固定維度循環狀態的無損精確回憶上界，與混血架構（Hybrid SSM / Liquid-Transformer）：理論與實證都顯示，不論是 Mamba、RWKV 或 CfC，只要把長度 N 的歷史壓進固定大小的狀態 O(d)，依鴿籠原理與資訊瓶頸，就無法像保留完整 KV Cache 的 01_Transformer核心 那樣，對任意早期的冷門細節做零誤差的精確查表。2026 年的研究已不再堅持用純架構取代注意力。現在的做法是大部分層用線性狀態空間／液態層處理連續時序動態，少數關鍵層穿插注意力做全局精準錨定（如伺服機構少樣本增量故障診斷的 Liquid-Transformer，Zhang et al., 2026）。
  2. 潛空間世界模型（JEPA）的表徵崩塌、局域微弱訊號漏檢與對抗脆弱性：JEPA 避開了像素空間的雜訊，但也少了「能不能重建出合理影像」這個直觀的檢驗。本領域收錄的兩篇 2026 L5 審核論文各指出一個問題。AG-JEPA（Singh et al., 2026）證實通用 JEPA 會忽略輕度認知障礙（MCI）轉化期只出現在少數腦區的微弱萎縮訊號，必須注入解剖學先驗遮罩。Cracks in Embeddings（Mansur et al., 2026）在近八萬張胸腔 X 光上發現，JEPA 嵌入空間在邊界黑盒攻擊與亮度／對比度臨床偏移下會發生結構性漂移。怎麼在非生成潛空間內建立可驗證的幾何穩定保證，是高風險醫療與自動駕駛世界模型急需解決的問題。

可以借到其他領域的結構

  • HiPPO 線上正交函數基底投影 → 持續學習與非平穩長時序記憶：Gu 等人（2021）用一組常微分方程，即時維護歷史訊號在 Legendre／Laguerre 多項式上的最優逼近係數。這種有界維度、滾動視窗與指數衰減的連續函數投影，可以直接搬到 07_發展式學習 的抗災難性遺忘記憶緩衝區，以及金融高頻微結構建模。
  • 在抽象不變量空間預測，不在觀測雜訊空間重建（JEPA 原則）：面對高雜訊的分子動力學軌跡、腦電圖或社會輿論演化（09_社會與多智能體、08_情感腦認知），不去預測微觀隨機漲落，改成預測慢變數（Slow Collective Variables）的潛表徵，樣本效率會高很多。
  • 萬維擬正交全息綁定（Kanerva HDC 向量符號架構）→ 機械可解釋性與神經符號橋接：34_高維機率與隨機矩陣 的測度集中保證，D 維球面上可以放進指數級數量 \exp(c \varepsilon^2 D) 個近似正交的概念向量。這是超維計算的數學根基，也替 06_學習動力學與可解釋性 中的特徵疊加態（Superposition Hypothesis）提供了一個構造性模型。
