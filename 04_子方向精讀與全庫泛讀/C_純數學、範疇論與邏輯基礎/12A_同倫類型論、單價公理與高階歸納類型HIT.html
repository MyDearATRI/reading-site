G1｜3 分鐘泛讀速覽

核心定位

本子方向構成 HoTT與類型論 的基礎核心，把 Martin-Löf 內涵依賴類型論中的認同型別解釋為拓撲空間裡的道路空間與 \infty-群胚。它以單價公理把結構等價識別為型別相等，並透過高階歸納類型（HIT）在類型論內部進行合成同倫論與建構性數學推導，往下銜接 立方類型論、計算性單價與定向模態類型論 的計算化實現，往旁對接 擬範疇、完備Segal空間與無窮範疇模型獨立基礎 的高階範疇語意。

  • 核心問題：傳統集合論基礎下的 ZFC 把數學對象拆解為與集合元素層級綁定的編碼，使同構對象無法自動互換；而在經典外延類型論中，等式反射規則（equality reflection）雖然能做代數替換，卻破壞了型別檢查的可判定性。相對地，內涵類型論雖保持可判定型別檢查，但預設的認同型別缺乏函數外延性、商空間構造以及區分命題與高階空間的手段，使得形式化拓撲學與代數結構陷入繁瑣的 setoid 等價類維護成本。
  • 直覺模型：在經典邏輯裡，判斷兩個元素是否相等像在檢查兩顆完全相同的鋼珠，只有「相等」或「不相等」兩種結果；同倫類型論則把型別看成幾何空間，把相等證明看成連接兩點的連續路徑。兩點之間可以有多條不同路徑，路徑之間又有同倫變形，形成無限向上的維度塔，而單價公理就是規定兩個空間只要能彼此連續變形同倫等價，它們在宇宙型別裡就有一條連接彼此的相等路徑。
  • 分階段閱讀路線：第一階段先讀 The Univalent Foundations Program (2013) 建立認同型別、單價公理與高階歸納類型的語法直覺，並配合 Kapulkin 與 Lumsdaine (2012) 理解單純集合與萬有 Kan 纖維化如何給出單價宇宙的一致性模型。第二階段精讀 Lumsdaine 與 Shulman (2017) 掌握任意模型範疇中以帶參數胞腔單子建構高階歸納類型的嚴格語意，再讀 Brunerie (2016) 體會合成同倫論如何純粹在型別內部算出 \pi_4(S^3) \simeq \mathbb{Z}/2\mathbb{Z}。第三階段閱讀 2026 年前沿，先看 Cavallo 與 Höfer (2026) 釐清範疇單價與函數外延性的界線，再看 Brough (2026) 在 Cubical Agda 中實作無公理假設的 Cauchy 實數高階歸納歸納型別。

核心機制與推導要點

  1. 認同型別與同倫層級（Identity Types and Homotopy Levels）

    • 直覺理解：型別不再被強制視為只有元素的離散集合，而是依據「高階路徑何時退化為平凡」分出可縮空間、命題、集合與高階群胚，讓普通離散數學與拓撲空間共存於同一套型別規則。
    • 機制或核心表達式：在 Martin-Löf 類型論中，對 x, y : A 的認同型別 x =_A y 由自反項 \mathrm{refl}_x : x =_A x 與路徑歸納法（J-消去子）定義。Voevodsky 以歸納定義同倫層級：(-2)-截斷為可縮型別 \mathrm{isContr}(A) := \sum_{a:A} \prod_{x:A} (a =_A x)；對 n \ge -2，型別 A 為 (n+1)-型別當且僅當 \prod_{x,y:A} \mathrm{is}\text{-}n\text{-type}(x =_A y)。其中 (-1)-型別為至多只有一個等價元素的命題，0-型別為滿足認同證明唯一性（UIP）的集合。
    • 能做到什麼，代價是什麼：同倫層級把集合論的唯一性公理轉化為可檢驗的內在性質，讓普通代數結構仍能安全做集合層面的證明；代價是在構造商型別或截斷型別時必須明確追蹤截斷層級，無法不加區分地對所有型別使用排中律或全域選擇公理。

  2. 單價公理與函數外延性（Univalence Axiom and Function Extensionality）

    • 直覺理解：單價公理保證型別宇宙中的「相等」不多不少剛好等價於兩個型別之間的「等價關係」，使同構不變的數學性質能直接沿著相等路徑自動遷移，不用重複搬運結構證明。
    • 機制或核心表達式：對某個宇宙 \mathcal{U} 與型別 A, B : \mathcal{U}，透過路徑歸納法可定義標準映射 \mathrm{idtoeqv}_{A,B} : (A =_{\mathcal{U}} B) \to (A \simeq B)，其中 A \simeq B := \sum_{f:A \to B} \mathrm{isEquiv}(f)。單價公理斷言 \mathrm{idtoeqv}_{A,B} 本身是一個等價，即 (A =_{\mathcal{U}} B) \simeq (A \simeq B)。Voevodsky 證明只要宇宙滿足單價公理，就能推出函數外延性（\prod_{x:A} f(x) = g(x) 等價於 f = g）；然而 Cavallo 與 Höfer (2026) 利用 Von Glehn 的多項式模型構造出反例，證明僅要求宇宙構成的野範疇（wild category）滿足範疇單價並不足以推得函數外延性。
    • 能做到什麼，代價是什麼：在傳統 Martin-Löf 類型論中直接把單價當成外部公理會讓閉合自然數或布林項目停止化簡至正規形式，促使 立方類型論、計算性單價與定向模態類型論 發展具有計算性的立方語法；同時單價與嚴格的全域 UIP 相矛盾。

  3. 高階歸納類型與合成同倫論（Higher Inductive Types and Synthetic Homotopy Theory）

    • 直覺理解：高階歸納類型在定義資料型別時不只允許宣告「點」建構子，還允許同時宣告點之間的「路徑」建構子與高維胞腔，因此能直接把圓周 S^1、球面 S^n、同倫推出與命題截斷寫進型別系統。
    • 機制或核心表達式：以圓周 S^1 為例，其由點建構子 \mathrm{base} : S^1 與路徑建構子 \mathrm{loop} : \mathrm{base} =_{S^1} \mathrm{base} 生成，消去規則要求給定依賴型別 P : S^1 \to \mathcal{U} 時需同時提供 b : P(\mathrm{base}) 與沿著 \mathrm{loop} 的依賴路徑 \ell : \mathrm{transport}^P(\mathrm{loop}, b) = b。在語意上，Lumsdaine 與 Shulman (2017) 提出帶參數胞腔單子（cell monad with parameters），證明在適當的 Quillen 模型範疇中可藉局部宇宙構造獲得嚴格穩定的弱初始代數，涵蓋球面、環面、James 構造與一般局部化。這套工具讓 Brunerie (2016) 能在不依賴點集拓撲下建立 Freudenthal 懸垂定理、Hopf 不變量與 Gysin 正合列並證明 \pi_4(S^3) \simeq \mathbb{Z}/2\mathbb{Z}。
    • 能做到什麼，代價是什麼：合成方法跳過大量拓撲點集與測度細節，證明可直接編譯為機器可驗證腳本（如 Brough 2026 形式化 Cauchy 實數）；但其語意合法性高度依賴胞腔規則的嚴格正性（strict positivity）條件，且高維相干律的計算複雜度在複雜 HIT 上會迅速上升。

主動學習自測題

  1. 為何單價公理與普遍的認同證明唯一性（UIP）不相容：在同倫類型論中，如果把布林型別 \mathbf{2} 上的恆等映射 \mathrm{id}_{\mathbf{2}} 與取反映射 \mathrm{not} 都視為 \mathbf{2} \simeq \mathbf{2} 的元素，如何利用單價公理證明宇宙 \mathcal{U} 不是一個 0-型別（集合）？
參考思路

取宇宙中的型別 \mathbf{2} : \mathcal{U}。自反路徑 \mathrm{refl}_{\mathbf{2}} 經由 \mathrm{idtoeqv} 映到恆等自同構 \mathrm{id}_{\mathbf{2}}；同時取反函數 \mathrm{not} 也是 \mathbf{2} \simeq \mathbf{2} 的等價，依單價公理存在路徑 p : \mathbf{2} =_{\mathcal{U}} \mathbf{2} 使得 \mathrm{idtoeqv}(p) = \mathrm{not}。因為 \mathrm{id}_{\mathbf{2}}(\mathrm{true}) = \mathrm{true} \neq \mathrm{false} = \mathrm{not}(\mathrm{true})，這兩個等價並不相等，因此 p \neq \mathrm{refl}_{\mathbf{2}}，從而說明 \mathbf{2} =_{\mathcal{U}} \mathbf{2} 至少有兩個相異路徑，宇宙 \mathcal{U} 不滿足 UIP。

  1. 單純集合模型為何無法僅在集合範疇中構造，以及高階歸納類型的語意條件：在 Kapulkin 與 Lumsdaine (2012) 的單純集合模型與 Lumsdaine 與 Shulman (2017) 的高階歸納類型語意中，宇宙的相干問題（coherence problem）如何透過萬有 Kan 纖維化或局部宇宙構造來解決？
參考思路

在範疇語意裡，依賴型別替代（substitution）在語法上是嚴格結合與嚴格分配的，但單純集合模型或一般模型範疇裡的拉回（pullback）只在同構意義下結合，這會導致對解釋的相干失配。Kapulkin 與 Lumsdaine 利用有限生成態射分類與（弱）萬有 Kan 纖維化建立嚴格的語境範疇宇宙，讓所有替代直接對應宇宙映射的嚴格複合。Lumsdaine 與 Shulman 則進一步把局部宇宙構造（local universes construction）套用到帶參數胞腔單子的弱穩定初始代數上，確保各類 HIT 的消去規則在替代下維持嚴格穩定。

G3｜跨領域連結與開放問題

學界目前的爭論與未解問題

  1. 直謂性基礎下的高階歸納類型與點無關拓撲的極限：在不使用命題調整公理（propositional resizing）的直謂性單價基礎中，許多經典拓撲與Locale建構看似依賴非直謂量化；Tosun (2026) 已證明在自然大小假設下可直接以框架（frames）建構譜與 Stone Locale 理論，但如何將一般無點拓撲與大範疇局部化的直謂性邊界完全釐清仍是開放研究。
  2. 從無窮群胚走向內聚與定向合成幾何的統一語法：標準 HoTT 只能作為對稱性 (\infty,0)-群胚的內部語言，無法直接區分連續拓撲與同倫形變，也無法刻畫單向態射的 (\infty,1)-範疇。Shulman (2015) 以實內聚 HoTT 證明 Brouwer 不動點定理，而 Riehl 與 Shulman (2017) 及 Cavallo 等人 (2026) 則推進單純類型論與定向單價，但如何把這幾種模態與立方計算性統一為單一實用的證明系統尚未定論。

跨領域結構遷移

  • HIT 胞腔規格與組合式神經架構：Sargsyan (2026) 把高階歸納類型的基點、路徑建構子與 2-胞腔直接編譯為嚴格么半函子式的神經傳輸解碼器，讓網路輸出沿著代數商空間定律做組合泛化並在環面與 Klein 瓶任務上優於標準注意力機制；此想法可跨界遷移至 高階範疇、同倫類型論與凝聚合成幾何 與 弦圖演算、對稱么半範疇與範疇量子力學ZX演算 的組合性表徵設計。
  • 實內聚型別與高階規範場幾何：HoTT 中透過明確變數（crisp variables）與離散／餘離散伴隨模態分離「同倫路徑」與「連續道路」的技術（Shulman 2015），可直接遷移至 內聚無窮Topos、微分上同調與高階規範場幾何 作為內聚 (\infty,1)-Topos 的內部類型語言，並接軌 擬範疇、完備Segal空間與無窮範疇模型獨立基礎 的模型獨立驗證。

4. On the homotopy groups of spheres in homotopy type theory（2016）

5. Univalence without function extensionality（2026）

  • 作者與出處：Evan Cavallo, Jonas Höfer · arXiv
  • 核心問題：經典 Voevodsky 定理指出單價宇宙內含函數外延性；若把單價公理弱化為只要求宇宙構成的野範疇滿足範疇單價（categorical univalence），是否仍能推出函數外延性？
  • 關鍵做法：作者分析 Von Glehn 的多項式模型構造（該構造產出的 Martin-Löf 類型論模型必定反駁函數外延性），證明當基底模型擁有單價宇宙時，其多項式模型的宇宙滿足範疇單價但仍缺乏函數外延性。
  • 跨領域啟發：精準切割單價公理與函數外延性之間的推論依賴關係，對 依賴類型論範疇語意與Agda及Rocq證明工程 中的最小公理模型設計有直接參考。
